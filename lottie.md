# Контекст проекта

## Цель

Необходимо реализовать процесс создания **простых `.lottie` анимаций** для веб-приложения на основе существующих PNG-изображений.

Использование Adobe After Effects и другого тяжелого ПО **не планируется**. Основной рабочий процесс должен строиться на открытых инструментах Lottie и автоматизации.

---

# Исходные данные

В проекте уже существуют PNG-ассеты (скины, предметы, подарки и т.п.), которые используются в веб-приложении.

Необходимо создавать простые анимации:

* плавное появление (fade-in);
* исчезновение (fade-out);
* масштабирование (scale);
* покачивание (rotation);
* небольшое движение (translate);
* пульсация;
* комбинации перечисленных эффектов.
* изменение констуркций и состояний 

Анимации должны экспортироваться в формате `.lottie` (или Lottie JSON с последующей упаковкой в `.lottie`).

# Исследованные инструменты

## 1. Lottie Docs Playground

[https://lottiefiles.github.io/lottie-docs/](https://lottiefiles.github.io/lottie-docs/)

Изучены:

### JSON Editor

Позволяет:

* просматривать Lottie JSON;
* редактировать структуру анимации;
* тестировать результат.

Ограничения:

* отсутствует полноценная загрузка PNG;
* изображения должны быть встроены в JSON как Base64 assets;
* предназначен скорее для редактирования уже существующих анимаций.

---

### Builder Playground

Позволяет:

* создавать простые анимации визуально;
* работать с примитивами;
* изучать структуру Lottie.

Недостатки:

* ограниченная функциональность;
* отсутствует полноценный импорт внешних PNG;
* подходит скорее для обучения и прототипирования.

# Что должно получиться

В результате должен существовать простой API.

Например:

```python
generate_animation(
    image="flower_1.png",
    effect="pulse",
    duration=2,
    output="flower_1.lottie"
)
```

или

```python
animate_png(
    image="diamond.png",
    animation="fade_scale",
    fps=60,
    loop=True
)
```

который автоматически создаёт готовую Lottie-анимацию.

---

# Конечная цель

Получить полностью автоматизированный процесс генерации простых Lottie-анимаций без использования After Effects и ручного редактирования JSON.

Решение должно быть масштабируемым: новые эффекты должны добавляться как отдельные шаблоны, а генерация анимаций должна происходить программно из набора PNG-ассетов. Это позволит в дальнейшем интегрировать генерацию анимаций в бэкенд или в пайплайн сборки проекта.
